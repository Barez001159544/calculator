# React Calculator

A simple and clean React project featuring a fully functional calculator with support for all basic arithmetic operations.

## Features
- **Calculation Screen**: Displays both the input expression and the result in a clean top section.
- **Error Handling**: Prevents invalid operations and handles edge cases gracefully.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **React Hooks**: Uses `useState` for state management.

## Installation

1. **Clone the repository**  
   ```sh
   git clone https://github.com/Barez001159544/calculator.git
2. **Navigate to the project directory**  
   ```sh
   cd calculator
3. **Install dependencies**  
   ```sh
   npm install
4. **Start the development server**  
   ```sh
   npm start
